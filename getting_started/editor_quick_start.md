# Editor quick start

1. **Edit the scene**: click an object in the viewport or pick it in the scene tree, then drag the gizmo or type values in the inspector.
2. **▶ Play (F5)**: runs the game right away with the scene you are editing. `F5` again returns to editing (the scene is not changed); `Esc` goes to the game (its pause menu). Disabled until the game code is loaded.
3. **Ctrl+S**: save. The game and multiplayer use the project's start scene, `assets/scenes/arena.scene` in the example (`scene` in `mealkit.project`, editor Project > Settings).
4. **Ctrl+R**: build the game code (hot reload). **Ctrl+B**: release build (`export/<game>/`). The Build menu can also open the release and project folders.

All mouse and keyboard controls are listed in {doc}`../manual/editor`.
