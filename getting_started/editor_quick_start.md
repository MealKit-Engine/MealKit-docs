# Editor quick start

1. **Edit the scene in MkRender**: **Tools > MkRender** (or **Open in MkRender** on a scene) opens it; click an object, drag the gizmo or type values in the inspector, and save with Ctrl+S ({doc}`../manual/scene_editor`).
2. **▶ Play (F5)**: runs the game right away with the open scene as saved (in MkRender, F5 asks the editor to play). `F5` again returns to editing (the scene is not changed); `Esc` goes to the game (its pause menu). Disabled until the game code is loaded.
3. **Start scene**: the game and multiplayer use the project's start scene, `assets/scenes/arena.scene` in the example (`scene` in `mealkit.project`, editor Project > Settings).
4. **Ctrl+R**: build the game code (hot reload). **Ctrl+B**: release build (`export/<game>/`). The Build menu can also open the release and project folders.

The editor controls are in {doc}`../manual/editor`, the scene editor's in {doc}`../manual/scene_editor`.
